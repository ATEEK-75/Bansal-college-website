# Bansal Institute Website

This is a college website project I created using HTML, CSS, and JavaScript. The main purpose of this project was to practice web development and build a website related to my college.

## About the Project

The website presents information about Bansal Institute through a simple and user-friendly design. I created this project to improve my front-end development skills and get practical experience with website design.

## Technologies Used

* HTML5 – Website structure
* CSS3 – Styling and layout
* JavaScript – Interactive elements

## Features

* Clean website layout
* College-related information
* Styled sections and navigation
* Interactive elements using JavaScript

## Project Structure

```text
bansal-college-website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## What I Learned

While building this project, I practised HTML page structure, CSS styling, and JavaScript functionality. It also helped me understand how these three technologies work together to create a website.
